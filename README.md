# 공정감사위원회 업무 자동화 시스템

## 📌 개요

이 프로젝트는 학생회 공정감사위원회의 회계 감사 업무를 자동화하기 위한 시스템입니다.
사무감사교육자료에 명시된 규정을 **기계가 판정 가능한 규칙으로 변환**하여, 결산안과 통장거래내역을 자동으로 검토합니다.

시스템은 다음 두 가지 파일을 입력으로 받습니다:

* 월별 결산안 (엑셀)
* 통장거래내역 (엑셀)

이후 규정 위반 여부를 판단하고, 다음 정보를 사용자에게 제공합니다:

* 오류 위치 (행/열)
* 오류 발생 이유 (규정 근거)
* 수정 방법
* 3차 기준 예상 벌점

---

## 🎯 프로젝트 목적

기존 감사는 사람이 직접 다음 세 가지를 동시에 검토해야 했습니다.

1. 형식이 맞는가
2. 거래가 맞는가
3. 증빙이 맞는가

이 프로젝트는 이러한 반복적이고 복잡한 감사 과정을 자동화하여
👉 감사 효율성과 정확도를 동시에 향상시키는 것을 목표로 합니다.

---

## 🧠 핵심 개념

이 시스템은 단순히 파일을 읽는 프로그램이 아니라,
👉 **규정을 실행 가능한 조건으로 변환하는 “규정 기반 감사 엔진”**입니다.

시스템은 다음 네 가지 핵심 엔진으로 구성됩니다:

* 형식 규칙 엔진
* 거래 매칭 엔진
* 증빙 판독 엔진
* 벌점 산정 엔진

---

## 🔍 감사 구조 (3단계 구조)

사람 감사위원이 수행하는 감사 과정은 다음과 같은 3단 구조를 가집니다:

1. **형식 감사**

   * 파일명, 시트명, 수식, 구조 등 검증

2. **거래 감사**

   * 결산안과 통장거래내역 간 일치 여부 검증

3. **증빙 감사**

   * 영수증 및 증빙자료 존재 및 적합성 검증

시스템 역시 동일한 구조를 따릅니다:

* 1단계: 형식 감사
* 2단계: 거래 매칭
* 3단계: 증빙 검증
* 최종: 벌점 산정 및 결과 리포트 생성

---

## ⚙️ 전체 동작 흐름

```text
업로드 → 형식 검사 → 거래 매칭 → 증빙 추출 → OCR 분석 → 규칙 판정 → 결과 리포트 → 벌점 산정
```

---

## 📂 입력 데이터

* 결산안 엑셀 파일
* 통장거래내역 엑셀 파일
* (결산안 내 노트에 포함된) 증빙 이미지

---

## 📊 출력 결과

시스템은 다음과 같은 형태의 감사 결과를 제공합니다:

* 오류 발생 위치 (행, 열)
* 위반 규칙
* 오류 발생 이유
* 관련 규정 페이지
* 수정 방법
* 예상 벌점

즉 단순 오류 탐지가 아니라
👉 **감사위원 답안지 형태의 설명형 리포트**를 생성합니다.
